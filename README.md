# TempleOS - Fork

> **⚠️ STATUS DO PROJETO: PAUSADO / IDEIA FUTURA** > Este repositório é um *fork* pessoal do TempleOS. No momento, o projeto está congelado e serve apenas como um arquivo de ideias e estudos para o futuro. Não há desenvolvimento ativo ou previsão de atualizações.

---

## 🎯 Objetivo do Fork

A intenção deste repositório é preservar o código-fonte original e estruturar uma base para experimentos futuros. 

**Ideias de Gaveta para o Futuro:**
* **Estudo de Arquitetura:** Analisar o funcionamento do compilador HolyC e do kernel do sistema.
* **Experimentos:** Testar modificações conceituais ou pequenas customizações na interface.
* **Preservação:** Manter um ambiente funcional para rodar e entender as aplicações nativas.

Alumas Ideias:
* **Reprojetar a Interface:** Deixa a interface parecida com a do Windows 3.0 ou dos MS/DOS 1.0
* **Driver de Áudio:** Driver de áudio que tenha mais de uma channel.
